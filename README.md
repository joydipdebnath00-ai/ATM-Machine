# 🏧 ATM Machine – Java

A simple **ATM Machine simulation built using Java**. This project replicates basic ATM operations through a console-based interface and is designed to practice Java programming and Object-Oriented Programming concepts.

## 🚀 Features

* 🔐 User PIN authentication
* 💰 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 📊 Balance validation
* 🚪 Exit/logout functionality
* ⚠️ Handles invalid input and insufficient balance

## 🛠️ Technologies Used

* **Java**
* Object-Oriented Programming (OOP)
* Conditional Statements
* Loops
* Methods
* User Input using `Scanner`

## 🎯 Purpose

This project was created to strengthen my **Java fundamentals and problem-solving skills** by implementing a real-world banking/ATM scenario.

## 📚 Concepts Practiced

* Classes and Objects
* Encapsulation
* Methods
* Variables and Data Types
* `if-else` / `switch`
* Loops
* Exception and input handling
* Basic transaction logic

## ▶️ How to Run

1. Clone this repository.
2. Open the project in any Java-supported IDE such as IntelliJ IDEA, Eclipse, or VS Code.
3. Compile the Java file.
4. Run the program.
5. Follow the instructions displayed in the console.
